# Interview preparation roadmap

This roadmap is designed for engineers who want a structured study plan without turning preparation into a random collection of articles and questions.

## Phase 1: Foundation

Focus on the core system design and backend topics you are expected to know:

- data structures and time complexity
- HTTP, networking, and API design
- database fundamentals
- caching and indexing
- concurrency and trade-offs
- observability and debugging

## Phase 2: Practice loops

Set up a study routine that includes:

- 2-3 timed backend questions per week
- 1 system design prompt per week
- 2 behavioral prompts per week
- one rubric review after each practice session

Use a simple format:

1. read the prompt
2. clarify assumptions
3. think aloud
4. propose an approach
5. discuss trade-offs
6. score yourself

## Phase 3: Feedback and iteration

After each mock interview, write down:

- what you explained well
- where you got stuck
- which areas felt fuzzy
- what you would do differently next time

This is where candidates improve most:

- better structure
- better trade-off discussion
- stronger communication
- more confidence under time pressure

## Phase 4: Role-specific depth

Adjust your study plan by role:

### Backend engineer

- API design
- database design
- distributed systems basics
- queues and async processing
- reliability and failure modes

### Frontend engineer

- rendering performance
- state management
- network and caching trade-offs
- browser constraints
- accessibility and UX

### Full-stack engineer

- end-to-end architecture
- API contracts
- data flow and deployment
- monitoring and operational concerns

### Data/ML engineer

- data pipelines
- modeling trade-offs
- system performance
- inference and reliability concerns

## Suggested weekly rhythm

- Monday: review one concept and take notes
- Tuesday: practice one backend prompt
- Wednesday: system design discussion
- Thursday: behavioral STAR practice
- Friday: score and review your answers
- Weekend: focus on weak spots

## Keep it practical

The best interview prep is repeatable, measurable, and rooted in real engineering scenarios.
