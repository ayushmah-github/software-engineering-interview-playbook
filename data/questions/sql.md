# SQL interview questions

This file contains realistic SQL interviews prompts for data-focused and backend-heavy roles.

## Core prompts

1. Find the top 3 products by revenue in each region.
2. Write a query to detect duplicate customer records.
3. Explain the difference between inner joins, left joins, and semi joins.
4. Design a query to compute retention across weekly cohorts.
5. Explain how indexing changes query performance.
6. How would you identify slow queries in a production database?
7. Write a SQL query to find customers with no orders in the last 90 days.
8. Explain the trade-offs of using materialized views in analytics workloads.
9. How would you handle missing data in reporting queries?
10. Describe how you would validate data integrity in a large table.

## Good answer structure

- state assumptions
- write out the query clearly
- explain edge cases
- discuss indexing and performance trade-offs
- mention data quality concerns where relevant
