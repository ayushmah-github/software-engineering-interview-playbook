# Python interview questions

This file contains practical Python interview prompts for backend, data, and general software engineering roles.

## Core prompts

1. Explain the difference between lists, tuples, sets, and dictionaries in Python.
2. How would you design a Python service for high-throughput API requests?
3. What are the trade-offs of async Python for I/O-heavy workloads?
4. How would you profile a Python application with performance regressions?
5. Describe how you would structure a Python project for maintainability and testing.
6. Explain how you would build a retry and timeout strategy for outbound HTTP calls.
7. What should you consider when processing large CSV or JSON files in Python?
8. How do you handle concurrency safely in Python services?
9. Explain how you would design a background worker for job processing.
10. How would you reason about memory usage in a Python data pipeline?

## Strong answers include

- practical trade-off analysis
- clear performance considerations
- attention to correctness and reliability
- structure that fits the role being targeted
