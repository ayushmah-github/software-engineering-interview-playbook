# Java interview questions

This file contains practical Java interview prompts for backend, platform, and enterprise-engineering candidates.

## Core prompts

1. Explain the difference between interface inheritance and class inheritance in Java.
2. How would you design a thread-safe cache in Java?
3. Explain how Java memory management affects application performance.
4. What are the trade-offs between using synchronized blocks and locks?
5. Describe how you would design a robust retry mechanism for downstream services.
6. How do you handle exceptions in service layers without hiding root causes?
7. Explain the impact of GC tuning on latency-sensitive services.
8. How would you design a production-grade API client in Java?
9. Describe a pattern for handling backpressure in message consumers.
10. How would you structure a Java application for testability and maintainability?

## Strong answers include

- clear architecture decisions
- knowledge of common Java libraries and patterns
- trade-off reasoning
- operational awareness
- examples that show production thinking
