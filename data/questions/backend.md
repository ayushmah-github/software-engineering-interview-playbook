# Backend interview questions

These prompts are intended to support realistic interview practice.

## Core prompts

1. Design a rate limiter for a public API.
2. How would you design a URL shortener with analytics?
3. Explain how you would debug intermittent database latency.
4. Design a notification worker with retries and backpressure handling.
5. How would you design a job queue for asynchronous processing?
6. Explain the trade-offs between read replicas and sharding.
7. How do you choose between synchronous and asynchronous communication?
8. Design a caching layer for a high-read traffic application.
9. How would you design a system to handle partial failures safely?
10. Explain how you would monitor and debug a production API with slow responses.

## Suggested practice format

For each prompt, answer:

- system assumptions
- key components
- failure modes
- trade-offs
- monitoring and operational considerations

## What good answers include

- reasonable assumptions
- clear architecture reasoning
- explicit trade-offs
- operational awareness
- ability to explain failure handling
