# System design interview questions

This file contains practical prompts for system design interviews and architecture discussions.

## Prompt set

1. Design a chat system for a product team.
2. Design a URL shortener with traffic spikes and analytics.
3. Design a notification service that supports millions of users.
4. Design a search system for product catalog data.
5. Design a file storage service with large uploads and sync.
6. Design an online judge or execution system for coding tasks.
7. Design a dashboard for operational observability.
8. Design a recommendation feed for a user-facing platform.
9. Design an event-driven analytics pipeline.
10. Design a payment or subscription orchestration flow.

## Strong answer structure

- requirements and scope
- capacity assumptions
- high-level architecture
- data model and storage choices
- bottlenecks and scaling strategy
- reliability and observability
- rollout or migration considerations

## Interview rubric focus

Look for clarity in trade-offs, not perfection. Good candidates explain why a design is reasonable under constraints.
